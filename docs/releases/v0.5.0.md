## 🎉 The first release

**Two of the same app, side by side, each signed in to its own account.**
Twinbar gives an Electron app (Slack, Discord, Postman, Bruno, Cursor, Claude,
...) a second copy on Windows with its own sign-in, its own Start menu entry,
its own taskbar button and its own icon. The original app isn't touched, and
both run at the same time: work and personal Slack, two Claude accounts, a
test login next to your real one.

![The same app's icon in Twinbar's four styles](https://github.com/sadrazkh/twinbar/raw/main/docs/styles.png)

### ✨ What you get

- 👯 **Profiles with their own sign-in.** Each profile keeps its sign-in,
  settings and data in a folder of its own, for normal installs, Squirrel
  installs (Slack, Discord, Postman...) and Microsoft Store apps such as
  Claude.
- 📌 **A taskbar button of its own.** A tiny launcher puts the profile's own
  ID on the app's windows, so it gets its own button. Pin it like any other.
- 🎨 **An icon of its own.** The app's icon recoloured, with a letter badge,
  or both, so you can tell the copies apart at a glance.
- 🪟 **The Twinbar window.** New, Edit, Open, Remove, Repair and Check all,
  with a live preview of the icon. No terminal needed.
- 🌗 **Light or dark per profile**, for apps that follow Windows' setting.
- 🩺 **`doctor`** checks every profile and says how to fix what's wrong;
  **`rebuild`** repairs one after the app moved or updated.

### 🧰 Under the hood

- One PowerShell script, using only what's built into Windows. No admin
  rights, nothing to install alongside it.
- Nothing is injected into the apps: they start with `--user-data-dir`, and the
  launcher only sets window properties.
- Removing a profile uses the Recycle Bin and keeps its sign-in unless you ask.

### 📦 In this release

The zip, a Scoop manifest, `SHA256SUMS`, and signed build provenance from
GitHub Actions. CI runs the tests and PSScriptAnalyzer on every push.
