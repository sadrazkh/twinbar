## ✈️ Telegram Desktop, twinned

**A second Telegram with its own sign-in and its own taskbar button.**
Telegram Desktop isn't built on Electron, but it has its own way of keeping
a separate data folder, and Twinbar now uses it. Work and personal Telegram
side by side, each in its own window with its own icon, and no limit of
three accounts in one app.

### ✨ New

- ✈️ **Telegram Desktop profiles.** Pick Telegram in **New profile...**, or
  `twinbar new -App Telegram -Name Work`. Twinbar starts Telegram with
  `-workdir` and the profile's own folder, so the twin has its own sign-in,
  chats, cache and settings, and gets its own taskbar button, icon, jump list
  and Start menu shortcut, like any other profile.
- 🔗 **Links stay with your main Telegram.** On its first start (and after
  each update) Telegram claims `tg://` links for itself. Twinbar turns on
  Telegram's own option that skips that in each twin, so clicking a
  Telegram link on a website keeps opening your main Telegram.
- 🧭 **Clearer messages for other apps.** Pick an app Twinbar can't twin and
  it says what it is: built on CEF (Steam, Spotify), a Chromium browser
  (use its own profiles), another Qt app, or Telegram from the Microsoft
  Store (get Telegram Desktop from telegram.org instead).
- 🏷️ **Apps by name.** `-App` now takes the name `twinbar apps` shows for
  any app it lists, `-App Telegram` or `-App Bruno`, not just Store apps.

```powershell
twinbar apps
twinbar new -App Telegram -Name Work -Color teal
twinbar open "Telegram Work"
```

### ℹ️ Good to know

- 🛰️ **Proxy and theme live in Telegram.** Each Telegram profile keeps its own:
  Settings > Advanced > Connection type, and Settings > Chat settings. So
  Twinbar's Proxy and Light/dark are turned off for Telegram.
- 🚀 **Leave "Launch Telegram when system starts" off in the twin.** Telegram
  has one start-up entry for all its copies, so turning it on in the twin
  would replace your main Telegram's.
- 🔔 Notifications from the twin show under Telegram's name, as Telegram
  sends them that way; the taskbar button and its window are the twin's own.
- 🧹 Telegram clears its own cache: Settings > Advanced > Manage local
  storage. `twinbar storage` still shows how much each profile takes.
- 🏪 Telegram from the Microsoft Store can't be given a folder of its own;
  use Telegram Desktop from telegram.org.
