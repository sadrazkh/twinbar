## 🪄 A real Windows installer

**Double-click, done.** Twinbar now comes as `Twinbar-Setup-0.5.1.exe`: it
installs for you only, with no admin rights, puts **Twinbar** in the Start
menu and opens it. No terminal, no unpacking.

### ✨ New

- 💿 **`Twinbar-Setup-<version>.exe`** in every release. It installs into
  `%LOCALAPPDATA%\Programs\Twinbar`, adds Twinbar to the Start menu and to
  **Settings > Apps**, and can put `twinbar` on your PATH (a checkbox).
- 🔁 **Upgrades in place.** Installing over an earlier version brings your
  profiles up to date too (`twinbar rebuild -All`).
- 🧹 **Clean uninstall.** Settings > Apps removes Twinbar; your profiles stay
  and keep working.
- 🖱️ **Double-clicking `twinbar.cmd`** now opens the Twinbar window instead of
  flashing the help text.

### 🧪 Tested on a clean machine

CI builds the installer on every push and tests a silent install, the window,
the installed command line and a silent uninstall on a fresh Windows runner.

### ℹ️ Good to know

The installer isn't code-signed yet (a certificate costs money), so Windows
SmartScreen may ask once: click **More info**, then **Run anyway**.
`Twinbar.exe` is still compiled on your own computer from the source inside
`twinbar.ps1`, so you can read exactly what runs.
