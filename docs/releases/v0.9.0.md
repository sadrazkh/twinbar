## 💾 Storage, cache and backups, plus your own switches

**Know what each profile takes, slim it down, and keep a copy you can bring
back.** This release adds a storage view, a cache cleaner that leaves your
sign-in alone, backups you can restore anywhere, and extra arguments and
environment variables for each profile.

### ✨ New

- 📊 **Storage.** `twinbar storage` (or **More... > Storage of the profiles**)
  shows how much each profile's data takes, and how much of it is cache.
- 🧹 **Clear cache.** `twinbar clean PROFILE`, or right-click a profile >
  **Clear cache...**. Only Chromium's caches go (Cache, Code Cache, GPU and
  shader caches, service worker caches, crash reports, in session partitions
  too). Your sign-in, settings and local data stay, and the app refills the
  cache as it needs it.
- 💾 **Back up.** `twinbar backup PROFILE`, or right-click > **Back up...**:
  the profile's settings and data in one zip, without the caches, in
  `Documents\Twinbar backups` unless you pick a file.
- ♻️ **Restore.** `twinbar restore FILE.zip`, or **More... > Restore a
  backup...**: the profile comes back with its look, proxy and options. Next
  to the original, it gets the next free name ("Work 2").
- 🎛️ **Your own switches.** `-AppArgs "--disable-gpu"` and
  `-Environment "NAME=value;NAME2=value"` for `new` and `change`, and
  **Arguments** and **Environment** in the New/Edit window.
- 🖱️ **Right-click a profile** in the window for everything it can do: Open,
  Edit, Check IP, Clear cache, Back up, Repair, Remove.

```powershell
twinbar storage
twinbar clean "Slack Work"
twinbar backup "Slack Work" -File D:\slack-work.zip
twinbar restore D:\slack-work.zip -Name "Work 2"
twinbar change "Bruno Work" -Environment "NODE_OPTIONS=--max-old-space-size=4096"
```

### ℹ️ Good to know

- 🔑 **A backup holds the profile's sign-in.** Keep it as safe as a password.
- 🖥️ **Another computer or Windows account?** Apps encrypt their sign-in with
  your Windows account, so the restored profile has its data and settings
  but will usually ask you to sign in again. Twinbar tells you when that's the
  case.
- 🛡️ Restoring checks that every file lands inside the new profile's folder;
  a zip that tries otherwise is refused and nothing is left behind.
- 🏪 Windows doesn't let Microsoft Store apps be given environment variables,
  so for them only the extra arguments apply.
