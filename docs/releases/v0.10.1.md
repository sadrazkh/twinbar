## 🩹 Telegram twins open as themselves

**If your Telegram profile brought up your main Telegram, this fixes it.**

### 🐛 Fixed

- ✈️ **A Telegram profile opened the main Telegram.** Updating Twinbar while
  another profile was open (Claude, say) left the older launcher in place:
  Windows doesn't let a running program's file be replaced. That launcher
  didn't know Telegram yet, so it started it the Electron way, and Telegram
  handed over to the copy already running. Now Twinbar moves the running
  launcher's file aside (Windows does allow renaming it), puts the new one in
  its place, and deletes the old one once it has quit. Opening a profile also
  checks the launcher is up to date first.
- 🛡️ A launcher that meets a kind of profile it doesn't know now says so,
  rather than starting the app the wrong way.

### ℹ️ Good to know

- Installing this update brings the launcher up to date even with profiles
  open; nothing else to do. Open your Telegram profile again and it starts
  as its own Telegram.
- Made a Telegram profile with 0.10.0 that showed the main Telegram? It's
  fine as it is: its own Telegram was never started, so it opens empty and
  asks you to sign in.
