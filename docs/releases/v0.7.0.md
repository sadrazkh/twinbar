## 🔄 Twinbar updates itself, and finds your proxy for you

**No more checking GitHub by hand.** Twinbar now tells you when a new version
is out, shows what's new, and installs it with one click. And when you set up
a proxy, it finds the ones running on your computer.

### ✨ New

- 🔔 **Update notices.** While its window is open, Twinbar checks GitHub once a
  day. When there's a new version it says so once, with what's new, and the
  version at the bottom right becomes an **Update to x.y.z** link.
- ⬇️ **Update now.** Twinbar downloads the installer, checks its SHA-256
  against the release's `SHA256SUMS` (and that it comes from Twinbar's own
  GitHub releases), closes, installs quietly over itself and opens again. Your
  profiles stay exactly as they are.
- ⌨️ **`twinbar update`** does the same from a terminal; `twinbar update -Check`
  only looks.
- 🧭 **Find... next to Proxy**, and **`twinbar proxies`**: the proxies running
  on this computer (v2rayN, Clash, Clash Verge, NekoRay, sing-box, Hiddify,
  Shadowsocks, Tor on their usual ports) and the one Windows is set to use.
  Each is tried as HTTP and as SOCKS5 and asked to connect out, so you see
  which **works**. HTTP comes first; pick one and it fills in the field.
- 🏷️ **Twinbar's version** at the bottom right of the window, and a **More...**
  menu: check for updates, turn the daily check off, find proxies, about.

```text
Proxies on this computer:
  http://127.0.0.1:10809     HTTP, works (Windows' proxy setting)
  socks5://127.0.0.1:10808   SOCKS5, works
Use it for a profile: twinbar change PROFILE -Proxy http://127.0.0.1:10809
```

### 🔐 Safe by design

The check and the download follow Windows' proxy setting, like a browser.
Downloads only come from this repository's releases, and an installer whose
SHA-256 doesn't match is deleted, never run. A Twinbar from Scoop is pointed
at `scoop update twinbar` instead.
